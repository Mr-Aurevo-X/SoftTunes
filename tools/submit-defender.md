# Soumission faux positif Microsoft Defender (gratuit)

Si Windows Defender ou SmartScreen signale Opti à tort :

1. Allez sur https://www.microsoft.com/wdsi/filesubmission
2. Choisissez « Software developer » / soumission de fichier
3. Envoyez `Opti.exe` (ou le zip du dossier onedir `dist\Opti`)
4. Expliquez : outil d’optimisation PC gaming local Mr-Aurevo-X, pas de réseau, open distribution via GitHub
5. Conservez le même `CompanyName` / `ProductName` sur les prochaines builds pour la réputation

SmartScreen sans certificat :
- « Informations complémentaires » → « Exécuter quand même »
- Documenté aussi dans Opti → À propos
