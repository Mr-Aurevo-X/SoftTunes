Politique de confidentialité (RGPD) — Opti

Responsable : Mr-Aurevo-X · © 2026

1. Pas de collecte

Opti fonctionne 100 % en local. Aucun compte, aucun serveur Mr-Aurevo-X, aucune télémétrie, aucun cookie publicitaire.

2. Données traitées sur votre PC

Des fichiers locaux peuvent être créés sous %LOCALAPPDATA%\Mr-Aurevo-X\Opti\ (sessions, undo, préférences). Ils restent sur votre machine. Vous pouvez les supprimer manuellement.

3. Bases légales

Traitement strictement nécessaire au fonctionnement du logiciel demandé par l’utilisateur.

4. Sous-traitants

Aucun sous-traitant cloud pour Opti. Les polices éventuelles chargées depuis Google Fonts (si connexion) relèvent de WebView ; le cœur métier n’envoie pas de données personnelles.

5. Vos droits

Comme aucune donnée n’est centralisée chez l’éditeur, les droits d’accès/effacement s’exercent en supprimant le dossier local Opti et en désinstallant l’application.

6. Contact

Via les dépôts GitHub Mr-Aurevo-X. Texte informatif.
